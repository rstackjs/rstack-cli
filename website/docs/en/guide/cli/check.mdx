# check

The `rs check` command runs lint and formatting checks for the current project, with optional TypeScript type checking.

## Usage

```bash
rs check [options] [files...]
```

Pass files or directories to limit both linting and formatting to those paths:

```bash
rs check src/index.ts packages/utils
```

## Checks

By default, `rs check` runs [`rs lint`](./lint) followed by [`rs fmt --check`](./fmt#--check) without modifying your files. It continues to check formatting even if linting or type checking reports errors, so you can see the results of all enabled checks in one run.

The command exits successfully only when all enabled checks pass. Errors that prevent a check from running, such as a failure to load the configuration, may stop the command early.

## Options

### `--fix`

Automatically fix linting and formatting issues:

```bash
rs check --fix
```

This runs `rs lint --fix` to apply available lint fixes. If linting and any enabled type checking pass, it then runs `rs fmt --write` to format the updated files.

### `--type-check`

By default, `rs check` checks only lint and formatting issues. Add `--type-check` to also check TypeScript types during linting:

```bash
rs check --type-check
```

### `-h, --help`

Display usage and option information without running checks:

```bash
rs check --help
```

## Configuration

`rs check` has no separate `define.check()` configuration. It uses the linting configuration from [`define.lint()`](../configuration#define-lint) and the formatting configuration from [`define.fmt()`](../configuration#define-fmt).
